Podstawowe polecenia

Przegląd poleceń .NET CLI
PolecenieOpis
dotnet --versionWyświetla wersję aktywnego SDK.
dotnet --list-sdksWyświetla zainstalowane zestawy SDK.
dotnet new listPokazuje dostępne szablony projektów.
dotnet new consoleTworzy projekt aplikacji konsolowej.
dotnet restorePrzywraca zależności projektu.
dotnet buildKompiluje projekt.
dotnet runKompiluje (jeśli potrzeba) i uruchamia aplikację.
dotnet cleanUsuwa wyniki wcześniejszych kompilacji.

Utworzenie i uruchomienie aplikacji

Wykonaj polecenia kolejno w terminalu. Projekt zostanie utworzony w osobnym katalogu.

dotnet --version
dotnet --list-sdks
dotnet new list
mkdir MojaAplikacja
cd MojaAplikacja
dotnet new console
dotnet restore
dotnet build
dotnet run
dotnet clean
