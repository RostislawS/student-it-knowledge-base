Wprowadzenie do Git

Git to rozproszony system kontroli wersji. Pozwala śledzić zmiany w plikach, tworzyć gałęzie i współpracować z innymi programistami.

Podstawowe polecenia Git

Najważniejsze polecenia Git
Polecenie Przykład Opis
git clone git clone URL Kopiuje repozytorium na komputer.
git status git status Pokazuje stan plików.
git add git add index.html Dodaje pliki do następnego commita.
git commit git commit -m "Opis" Zapisuje zmiany w historii.
git push git push origin main Wysyła zmiany na serwer.
git pull git pull origin main Pobiera i integruje zmiany.
git fetch git fetch origin Pobiera informacje o zmianach.
git branch git branch Wyświetla gałęzie.
git switch git switch main Przełącza gałąź.
git log git log --oneline Wyświetla historię commitów.

Typowy proces pracy z Git

  1. Synchronizacja projektu: git pull origin main
  2. Utworzenie gałęzi: git switch -c feature/name
  3. Wprowadzenie zmian w plikach.
  4. Dodanie zmian: git add .
  5. Zapisanie zmian: git commit -m "Opis"
  6. Wysłanie gałęzi: git push -u origin feature/name
  7. Utworzenie Pull Request na GitHub.
